# Honda NSX — The Art of Performance

Landing page copywriting Honda NSX dengan scroll-triggered animation, dibuat mobile-first.

## Stack

React 19 + TypeScript + Vite. Animasi memakai IntersectionObserver + CSS (tanpa library animasi tambahan).

## Menjalankan

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
npm run preview
```

## Catatan

- Seluruh teks mengikuti naskah copywriting yang diberikan.
- Aset kendaraan dioptimalkan ke WebP di `public/assets`.
